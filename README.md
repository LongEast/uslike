# Uslike MVP

React + Vite + Tailwind CSS prototype for the Uslike social workflow demo.

## Requirements

- Node.js 18 or newer
- npm

## Install

```bash
npm install
```

## Run Locally

Start the Vite development server:

```bash
npm run dev
```

Open the app in your browser:

```text
http://localhost:5173/
```

## Build

Create a production build:

```bash
npm run build
```

The built files will be generated in `dist/`.

## Preview Production Build

After building, preview the production output locally:

```bash
npm run preview
```

Then open the URL printed by Vite, usually:

```text
http://localhost:4173/
```
